Your agent needs a tool. AXLR forges it.

When no tool does what the task needs, the model writes one. You approve it, AXLR records the SHA-256 of every file, and the tool is still there in the next session. Change a file and it refuses to run until it is forged again. One open-source runtime in Go: a console, an mTLS service, a JSON worker and a library.

Agent workflows
